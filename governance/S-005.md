# S-005 — No Silent Assumptions

Constitution text: *"Unknown requirements produce questions, never guesses. ...
A governed decision to proceed with an explicit assumption is permitted only
when the assumption is recorded, approved, and traceable."*

---

## STEP 2 — Problem

Requirement gaps are filled silently with plausible guesses. Each guess hardens
into behavior nobody validated. This rule forces gaps to surface as structured
questions (RETRIEVE_EVIDENCE) and, when proceeding anyway, forces the
assumption into a recorded, approved, traceable record — or stops.

## STEP 3 — Concepts

- ambiguity
- material difference
- missing requirement
- question / request for evidence
- assumption
- fabrication

## STEP 4 — Deterministic Definitions

| Concept | Definition |
|---------|-----------|
| ambiguous requirement | A requirement with ≥2 distinct interpretations (GLOSSARY §3 records `requirementInterpretations`). |
| material difference | Two interpretations yield implementations that differ in observable behavior or artifact set. |
| missing requirement | A requirement referenced by a task/claim/artifact that does not exist in `requirements[]`. |
| question | A structured request for evidence with: `requirementId`, `question`, `options`. |
| assumption | GLOSSARY §11: recorded verbatim text, approving governed decision, traceable. |
| fabrication | Information introduced into requirements or claims that is absent from input AND not approved as an assumption. |
| permitted proceed | Proceeding is permitted iff the assumption is valid (GLOSSARY §11). |

## STEP 5 — Required State

- `requirements[]`
- `requirementInterpretations[]`
- `assumptions[]`
- `decisions[]`
- `request.type`

## STEP 6 — Triggers

- At requirement analysis, when a gap or ambiguity is detected
- Before implementation when a referenced requirement is missing

## STEP 7 — Algorithm

```
FOR each requirement R:

  // Missing
  IF R is referenced but absent from requirements[]
    THEN fail + emit question(R) — never synthesize R.

  // Ambiguous
  interpretations = requirementInterpretations[R]
  IF |interpretations| ≥ 2:
    IF interpretations differ materially:
      IF a valid assumption exists for R      // GLOSSARY §11
        THEN continue (proceed on the assumption)
      ELSE
        fail + emit question(R)               // RETRIEVE_EVIDENCE, do not guess
    ELSE
      continue                                // all interpretations agree → no material difference

  // Fabrication guard
  IF any requirement/claim content is not derivable from input
     AND not covered by a valid assumption
    THEN fail: "Fabricated requirement content."

pass
```

## STEP 8 — Tests

| Class | Case | Expected |
|-------|------|----------|
| normal | Clear, unambiguous requirement | pass |
| normal | Ambiguous but all interpretations produce identical implementation | pass (no material difference) |
| failure | Ambiguous with material difference, no assumption | fail + structured question emitted |
| failure | Referenced requirement missing | fail + question emitted |
| failure | Assumption present but approval decision = `RETRIEVE_EVIDENCE` | fail (not approved — GLOSSARY §11) |
| edge | Assumption approved and recorded → proceed | pass, assumption recorded in context |
| regression | Approved assumption later amended without human approval | fail (S-006) |
| adversarial | Assumption text recorded AFTER implementation artifacts exist | fail (must predate the artifacts it justifies) |
| adversarial | Fabricated requirement with a fake "approved" decision missing `validationReportId` | fail (GLOSSARY §1 invalid) |

## STEP 9 — Conflicts

- S-001: resolution in governance/README.md — an assumption satisfying this rule
  becomes part of the requirement set (amendment or new record) and thereby
  satisfies S-001's trace requirement.
- S-006: assumptions that amend approved requirements require human approval.
- Boundary note: this rule governs ENGINEERING requirements. The Experience
  Designer stage (experience architecture synthesis) is governed by the
  Experience Governor's own rules, not this constitution.
